📈 量化投资策略Web UI - 功能演示

🎯 核心功能

  • 可视化浏览12个量化投资策略
  • 按类别分组展示（基础入门、技术指标、A股回测、K线形态、强化学习等）
  • 支持查看策略详情和技术信息
  • 一键运行策略并查看执行结果
  • 预览回测绩效图（强化学习等策略）
  • 响应式设计，支持移动设备访问

启动方式

快速启动

cd webui
pip install -r requirements.txt
python app.py

# 访问: http://localhost:5000

或使用启动脚本

cd webui
./start.sh

技术架构

🔧 后端技术

  • Flask - Web框架
  • Python subprocess - 策略执行
  • RESTful API - 接口设计

🎨 前端技术

  • HTML5 + CSS3 - 页面结构和样式
  • 原生JavaScript - 交互逻辑
  • 响应式设计 - 移动适配

📊 策略支持

  • 12个策略 - 完整配置
  • 9个类别 - 分类管理
  • 图表预览 - 结果可视化
