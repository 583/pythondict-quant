# 量化投资策略Web UI

这是一个为量化投资教程项目开发的Web用户界面，提供可视化的策略浏览、查看回测绩效图和执行策略的功能。

## 功能特点

### 🎯 核心功能

1. **策略浏览** - 以卡片形式展示所有13个量化策略，按类别分组
2. **策略详情** - 查看每个策略的详细说明和技术信息
3. **回测绩效图预览** - 对于支持图表的策略，可以直接在Web界面查看回测图表
4. **策略执行** - 一键运行策略并查看执行结果
5. **响应式设计** - 支持桌面和移动设备访问

### 📊 支持的策略类别

- **基础入门** - 移动平均线策略
- **技术指标** - MACD、KDJ策略
- **A股回测** - 批量回测策略
- **策略分析** - 平均收益分析
- **K线形态** - 孕线策略
- **数据源** - 自定义MySQL数据源
- **监控系统** - Prometheus + Grafana监控
- **因子分析** - Alphalens因子回测
- **强化学习** - 基于PPO的自动交易

## 安装和使用

### 1. 安装依赖

```bash
cd webui
pip install -r requirements.txt
```

确保你已经安装了项目的其他依赖（backtrader等）：

```bash
pip install backtrader matplotlib pandas numpy
```

### 2. 启动Web服务器

```bash
python app.py
```

服务器将在 `http://localhost:5000` 启动。

### 3. 访问界面

打开浏览器访问：`http://localhost:5000`

## 界面使用说明

### 主页

- 显示所有策略的卡片，按类别分组
- 每个卡片显示策略名称、描述和是否支持图表
- 点击"查看详情"进入策略详情页
- 点击"运行策略"直接执行策略

### 策略详情页

- 显示策略的完整说明
- 如果策略有预览图片（如强化学习的收益图），会自动显示
- 点击图片可以放大查看
- 提供"运行策略"按钮执行策略
- 显示策略的技术信息（脚本路径、数据文件等）

### 运行策略

- 点击"运行策略"按钮后，会在模态框中显示执行进度
- 策略执行完成后，显示输出结果
- 如果策略有图表输出（使用`cerebro.plot()`），图表会在策略执行时显示

## 技术架构

- **后端框架**: Flask
- **前端**: HTML5 + CSS3 + JavaScript (原生)
- **界面设计**: 响应式设计，渐变色主题
- **策略执行**: subprocess模块调用Python脚本

## 注意事项

1. **策略执行时间** - 某些策略（特别是批量回测）可能需要较长时间执行，请耐心等待
2. **图表显示** - 使用`cerebro.plot()`的策略会弹出matplotlib窗口，需要在本地运行
3. **依赖要求** - 确保安装了所有必需的Python包（backtrader、matplotlib等）
4. **端口占用** - 默认使用5000端口，如需更改请修改`app.py`中的配置

## 安全提示

⚠️ 本Web UI仅供本地开发和学习使用，不建议直接暴露到公网。如需在生产环境使用，请：

1. 使用生产级WSGI服务器（如Gunicorn）
2. 配置适当的安全策略
3. 添加用户认证机制
4. 限制策略执行权限
